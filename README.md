# تطبيق شاعر الثورة مفدي زكريا (PWA)

تطبيق ويب تقدمي (PWA) تعليمي عن الشاعر مفدي زكريا. يعمل دون إنترنت بعد أول زيارة، ويمكن تثبيته على الهاتف.

## محتويات المجلد
- `index.html` الصفحة الرئيسية (كل الأقسام)
- `manifest.json` بيانات التثبيت
- `sw.js` عامل الخدمة (العمل دون اتصال)
- `icons/` الأيقونات (192، 512، maskable)
- `.nojekyll` يمنع معالجة Jekyll
- `.github/workflows/pages.yml` نشر تلقائي عبر GitHub Actions (اختياري)

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub (مثلاً `mufdi-zakaria`).
2. ارفع **محتويات** هذا المجلد إلى جذر المستودع (وليس المجلد نفسه).
3. من **Settings → Pages**:
   - إما: Source = *Deploy from a branch*، الفرع `main`، المجلد `/ (root)`.
   - أو: Source = *GitHub Actions* (سيستخدم ملف pages.yml).
4. بعد دقائق يظهر الرابط: `https://USERNAME.github.io/mufdi-zakaria/`
5. افتح الرابط على الهاتف ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
   رمز QR داخل التطبيق (قسم «تثبيت ومشاركة») يُنشأ تلقائياً من رابط الموقع.

## التحديث
غيّر `VERSION` في `sw.js` (مثل `mufdi-v2`) بعد أي تعديل ليحصل المستخدمون على النسخة الجديدة.

## ملاحظات
- شرط PWA: الموقع على HTTPS (GitHub Pages يوفره).
- صور الألبوم وملفات MP3 يضيفها المستخدم من جهازه وتُحفظ محلياً في متصفحه.
- نصوص قصائد مفدي زكريا محمية بحقوق النشر؛ لا تضفها إلا بترخيص.
